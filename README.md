# Low Magic Age em Português Brasileiro

Tradução completa do jogo **Low Magic Age** para o Português Brasileiro. Todos os textos da interface, itens, habilidades, classes, raças, monstros e diálogos foram traduzidos.

**Participe da comunidade no Discord:** <https://discord.gg/uFEwSMwUYb>

---

## Instalação

Siga os passos abaixo para instalar a tradução manualmente.

### 1. Baixar os arquivos

Baixe o arquivo `text.zip` ou `text.7z` da seção de [Releases do GitHub](https://github.com/isyuricunha/low-magic-age-portugues-brasileiro/releases) ou da página da tradução no [NexusMods](https://www.nexusmods.com/lowmagicage/mods/8).

### 2. Localizar a pasta do jogo

O caminho padrão da pasta do jogo no Steam é:

```
D:\SteamLibrary\steamapps\common\LowMagicAge
```

Mas o local pode ser diferente dependendo de onde você instalou o Steam. Exemplos comuns:

```
C:\Program Files (x86)\Steam\steamapps\common\LowMagicAge
E:\SteamLibrary\steamapps\common\LowMagicAge
F:\Jogos\Steam\steamapps\common\LowMagicAge
```

**Para abrir a pasta raiz do jogo pelo Steam:**

Na sua Biblioteca, clique com o botão direito em **Low Magic Age**, vá em **Gerenciar** e depois em **Explorar arquivos locais**. Isso abre a pasta do jogo automaticamente.

### 3. Copiar a tradução

Extraia o conteúdo do arquivo baixado. Você vai encontrar uma pasta chamada `text`.

Copie a pasta `text` para dentro da pasta raiz do jogo (a mesma que você abriu no passo anterior). Se o Steam perguntar se você deseja substituir um arquivo, confirme a substituição.

A estrutura final deve ficar assim:

```
LowMagicAge/
  text/
    langs.txt
    ptbr/
      advt_text.lua
      clss_text.lua
      cmn_text.lua
      hlp_text.lua
      itms_text.lua
      misc_text.lua
      mons_text.lua
      pwrs_text.lua
      races_text.lua
      skls_text.lua
      story_text.lua
```

### 4. Ativar no jogo

Abra o **Low Magic Age**. No menu principal, vá em **Settings** (Configurações). Na opção **Language**, selecione **Portugues Brasileiro**. Confirme a alteração. O jogo pode pedir para reiniciar. Feche e abra o jogo novamente.

Pronto! A tradução já estará ativa.
